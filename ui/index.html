Why this exists

Vision & Purpose

Berlin is a city of resistance. Protests, vigils, marches, and assemblies happen every day — but they're scattered across police bulletins, Instagram posts, and grassroots calendars. Uncolonised brings them together.

How to Contribute

Uncolonised is open to anyone who shares the vision. No experience needed — writers, scraper hackers, designers, and data people are all welcome.

1

Clone & Run

git clone, docker compose up, and you have a running instance. See the README.

2

Write an Article

POST /posts with a title, markdown body, and your name. No account needed.

3

Add a Scraper

Create a class in scraper/sources/, implement BaseScraper, register it in run_all.py.

4

Submit Events

Use POST /submit to tip us about events. The AI director reviews and publishes.
